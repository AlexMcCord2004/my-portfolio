🚀 Tech Stack
This portfolio is built using a modern, scalable web stack:

Next.js 14 — App Router, server components, routing
React 18 — Component-driven UI
TypeScript — Strong typing and reliability
Tailwind CSS v4 — Utility-first styling
Vercel — Deployment, hosting, CI/CD
Node.js — Underlying runtime for development
